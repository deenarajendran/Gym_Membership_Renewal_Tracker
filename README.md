This project is about building an interactive membership dashboard in Excel that helps track and analyze member plans. It uses PivotTables, charts, and slicers to visualize data such as:

Active vs Expired memberships

Plan durations by member

Expiry trends over time (monthly)

Plan type vs status (stacked bar chart)

The dashboard allows users to filter by Member Name, Status, and Plan Type, making it easy to identify patterns like the most chosen plan, upcoming expiries, and overall membership distribution.
